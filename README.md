# Родительский навигатор — мини-приложение

Статическое мобильное приложение для Telegram, MAX и обычного браузера. Внешние библиотеки для интерфейса не нужны. SDK MAX необязателен: при его недоступности карточки, навигация и поиск продолжают работать.

## Содержание и источники

- `data/family.json` — единый экспорт практических материалов обоих ботов: 6 семейных ситуаций и 12 игр. Не редактировать отдельно от исходных данных ботов.
- `data/program.json` — редакционный тематический путеводитель для родителей и педагогов. Восемь карточек не выдаются за официальное оглавление или одобренное приложение.
- Первоисточник: [программа ИРЗАР, 2024, 225 страниц](https://irzar.ru/wp-content/uploads/2024/12/programma-prosveshheniya-roditelej.pdf). Ссылки на страницы являются ориентирами по опубликованному PDF.
- Сохранённый `assets/program.pdf` — прежний ранний проект (288 страниц). Файл оставлен для сохранности; текущий интерфейс не предлагает его как актуальную редакцию.
- Практические рекомендации носят информационный характер, не диагностируют ребёнка и не заменяют индивидуальную помощь специалиста.

## Навигация и приватность

Главная страница, каталог ситуаций, игры с фильтрами по возрасту и задаче, восемь тем путеводителя и подробные карточки доступны по hash-ссылкам. История браузера работает без сервера маршрутизации. В SDK обработчик кнопки «Назад» регистрируется один раз.

В приложении нет форм, регистрации, аналитических счётчиков и сбора персональных данных. `localStorage` хранит только выбранный режим «родитель/педагог» под прежним ключом `mode`. Запрет хранилища не мешает работе. В режиме педагога добавляются краткие идеи для разговора с семьёй.

## Локальная проверка

```powershell
python -m http.server 8765 --bind 127.0.0.1
```

Открыть `http://127.0.0.1:8765/`. Проверка JavaScript: `node --check app.js`.

Автоматическая проверка требует Python и Playwright. Сначала запустить локальный сервер, затем:

```powershell
$env:APP_TEST_URL = 'http://127.0.0.1:8765/'
$env:PLAYWRIGHT_CHROME_EXECUTABLE = 'C:\Program Files\Google\Chrome\Application\chrome.exe'
python tests/test_app.py
```

Без `PLAYWRIGHT_CHROME_EXECUTABLE` используется установленный браузер Playwright. Скриншоты сохраняются в временную папку ОС. Перед публикацией проверять мобильный экран, сценарии, фильтры, пустой результат, недоступные данные, переключение режима, работу без хранилища и однократную регистрацию SDK-кнопки.

## Публикация

Это статические файлы для существующего GitHub Pages. При каждом выпуске менять версию в ссылках на CSS/JS в `index.html` и параметре загрузки JSON в `app.js`, чтобы снизить риск смешивания старых и новых файлов в кэше. PDF и остальные существующие материалы в `assets/` не перезаписывать без отдельной проверки.
